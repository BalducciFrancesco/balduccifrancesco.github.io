Personalised Multi-Modal Agent System for Bias Analysis INFS4205 Advanced Techniques for High Dimensional Data • University of Queensland
LLM Agents RAG LangGraph

During my exchange at the University of Queensland in Australia, I implemented a multimodal agent system for analyzing bias in YouTube watch histories. The project combined multiple LLM agents with LangChain and LangGraph to build a system capable of reasoning over both text and images, using retrieval-augmented generation to produce responses customized for the user's watch history. The work involved designing the full end-to-end pipeline: collecting and preparing the watch-history data, processing titles and thumbnails, generating embeddings and building the vector index used for later retrieval. I also developed custom tools for similarity search, session retrieval, bias-analysis sub-agents and evaluated the system's accuracy through a handcrafted LLM-as-a-Judge pipeline. To better benchmark the contribution of each component, I set up an ablation study to test how the system changed when features such as multi-modality, sub-agents, and fusion indexing were removed. I also built a public web interface that allows anyone to interact with the agent. The project was graded 15/15 for code and 18/20 for the report.

Node Centrality and Link Prediction in a Social Graph INFS7450 Social Media Analytics • University of Queensland
Graph Theory Centrality Link Prediction Graph Neural Network

During my exchange at the University of Queensland in Australia, I implemented a comparison and benchmark of different centrality and link predictions methods from different families and applied them to a social network structure. I implemented three approaches: a neighborhood-based method (Common Neighbors), a community-based method (Spectral Clustering) and an embedding-based method (Graph Convolutional Network). Since the target labels were not directly known for the test set, I came up with a cross-validation setup on a labeled split in order to select the most best performing method for prediction. A key part was comparing the strengths and weaknesses of each method, considering trade-offs like interpretability, flexibility, and accuracy. The project gave me hands-on experience with graph modeling, spectral methods, with a very interesting look at GNNs. It was also another opportunity to design fair benchmarking setups for problems with missing ground truth.

EEG Signal Processing for Motor Imagery Classification 22053 Principles of Brain-Computer Interfaces • DTU
EEG Signal Processing Convolutional Neural Network Cognitive Science

In this 3-week intensive course on brain-computer interfaces, I decided to work on an EEG-based motor imagery project about predicting left/right hand movement from imagined motion. I implemented a complete signal processing and classification pipeline on real EEG data with static and spatial filtering, feature extraction, and classification with different neural network classification methods. The project involved classical EEG preprocessing methods such as a notch filter and band-pass filtering, as well as spatial filtering with PCA and CSP. I then extracted time-frequency features using Fourier Transformation in order to train and compare two models: a feed-forward neural network and a convolutional neural network. I evaluated and compared the methods in a cross-validation architecture to obtain a reliable comparison of their accuracy. This project gave me hands-on experience with EEG analysis, signal processing, and model evaluation on a real-world dataset, while also strengthening my ability to compare neural network approaches in a rigorous way.

Manipulation of Belief Effects on AI-Generated Content 02455 Experiment in Cognitive Science • DTU
Experiment Design Cognitive Science Data Analysis

I designed and carried out an experiment about whether beliefs on AI-generated contents change our emotional responses, both qualitatively and quantitatively. The study used a within-subjects design with real videos as stimuli, each labeled as either AI-generated or human-generated, and measured participants' emotional responses through Self-Assessment Manikin (SAM) ratings and heart-rate variability (HRV) measurements. I worked on the full pipeline, including stimuli selection, experimental condition design, participant consent collection, preprocessing of the raw heart-rate data, and analyzing the results. The study used SAM ratings, RMSSD-based HRV analysis, Shapiro-Wilk testing, Wilcoxon signed-rank tests, and bootstrapped confidence intervals to rigorously compare the two conditions. This project allowed me to apply the knowledge from a previous course on experimental design while also working on physiological data analysis and rigorous statistical evaluation on a real-world dataset.

Primacy and Recency Effects in Memory Recall 02464 Artificial Intelligence for Human Cognition • DTU
Experiment Design Cognitive Science Data Analysis

I created an experiment to see how memory behaves in free recall and serial recall tasks. This was carried out through a hand-made experiment platform where participants memorized a curated list of character sequences and then recalled them either in sequential or random order. I contributed to designing, building and analyzing the full experiment pipeline, including the free-recall and serial-recall conditions, the different task variants (e.g., articulatory suppression, chunking, tapping), and the processing of the collected data in Python. Among its points, the analysis considered accuracy, Wilson confidence intervals, and charts to study as well as the impact of the task variants. This project provided me with experience on experimental design, behavioral data analysis, and interpreting memory functioning and effects.

Regression and Classification on Auto MPG Dataset 02450 Introduction to Machine Learning and Data Mining • DTU
Machine Learning Feature Extraction Data Analysis

I analyzed how vehicle characteristics relate to fuel efficiency and car origin. The course was a strong introduction to hands-on ML, covering the full workflow around data inspection, preprocessing, visualization, and rigorous evaluation of cross-validated results. In particular, I compared the impact of different normalization factors and examined how mpg relates to variables such as cylinders, displacement, horsepower, weight, and acceleration using pairplots, boxplots, histograms, and correlation matrices to explore the structure of the data. I then applied PCA to reduce the dimensionality of the dataset while preserving most of the variance, and used it to carry out regression and classification tasks. For the regression part, I compared simple ridge regression with an artificial neural network against a simple baseline using two-fold cross-validation. For the classification part, I compared multinomial logistic regression and an artificial neural network for predicting car origin, also with a two-level cross-validation setup. This project gave me crucial experience with pre-processing, feature extraction, model selection and comparison in a structured pipeline.

BScEng in Computer Science

Thesis: WhatToSee Website Back-End Bachelor's Thesis in Computer Science Engineering • Politecnico di Milano
Back-End Java Spring Boot REST API Testing Design Patterns

I developed the back-end of WhatToSee using Java 17, Spring Boot 3, and MySQL, with Spring Data JPA, Spring Boot Web, Lombok, JUnit 5, and Maven as the main supporting technologies. The system was designed around a layered architecture with controllers, DTOs, mappers, services, entities, repositories, exceptions, and utility classes, following an MVC style of architecture. A major part of the work was modeling the domain and persistence layer, including the relationships between users, tours, stops, tags, reviews, reports, and conversations. I implemented transactional business logic in the service layer and custom JPQL queries for flexible tour search. I key part was applying several design patterns, including Dependency Injection, Singleton, Factory Method, Strategy, and DTO-based decoupling, and implementing tests for the service layer using Spring Boot Test and Mockito.

Thesis: WhatToSee Website Front-End Bachelor's Thesis in Computer Science Engineering • Politecnico di Milano
Front-End Angular TypeScript UI/UX Design Patterns

I developed the front-end of WhatToSee using Angular 15, TypeScript 4.8, Node 18.12, Tailwind CSS, and Angular Material as the main supporting technologies. The application was structured around a modular architecture with pages, components, DTOs, services, utility classes, interceptors, guards, and routing modules, following an MVC separation. A major part of the work was building the client-side structure for navigation, authentication, and API communication with the back-end. I implemented reusable UI elements such as the tour page and tour card, together with service-based HTTP communication, a custom interceptor for authenticated requests, and route guards for access control. A key part was applying several design patterns, including Dependency Injection, Observer, Singleton, and MVC, while keeping the interface maintainable and decoupled from the back-end through DTO communication.
