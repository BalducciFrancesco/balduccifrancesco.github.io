MScEng in Human-Centered Artificial Intelligence

Advanced Techniques for High Dimensional Data Multi-Modality LLMs RAG Agents LangChain LangGraph

During my exchange at the University of Queensland in Australia, I implemented a multimodal agent system for analyzing bias in YouTube watch histories. The project combined multiple LLM agents with LangChain and LangGraph to build a system capable of reasoning over both text and images, using retrieval-augmented generation to produce responses customized for the user's watch history. The work involved designing the full end-to-end pipeline: collecting and preparing the watch-history data, processing titles and thumbnails, generating embeddings and building the vector index used for later retrieval. I also developed custom tools for similarity search, session retrieval, bias-analysis sub-agents and evaluated the system's accuracy through a handcrafted LLM-as-a-Judge pipeline. To better benchmark the contribution of each component, I set up an ablation study to test how the system changed when features such as multi-modality, sub-agents, and fusion indexing were removed. I also built a public web interface that allows anyone to interact with the agent. The project was graded 15/15 for code and 18/20 for the report.
